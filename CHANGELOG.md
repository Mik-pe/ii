# Release notes

## 0.1.1

- Update installation documentation to reflect the published crates.io package.
- Document repeatable releases, version updates and acceptance of the exact installed version.
- Include these release notes in the crate package.

There are no runtime behavior or dependency changes from 0.1.0. The package remains `in-i`, with the `ii` command and library.

## 0.1.0

First crates.io release as `in-i`.

- Directory-first browsing with contextual file categories and opt-in bounded deep folder search.
- Tab opens directories; Enter confirms the current browsing directory in the shell.
- Terminal, dark and light palettes, with `NO_COLOR` support.
- Preserve filter, selection and scroll through refresh and failed navigation.
- Scrollable help and preview overflow indicators.
- Bash, Zsh, Fish and Windows PowerShell integration with literal directory paths.
